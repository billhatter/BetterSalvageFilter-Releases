## Features

- All, Weapons, Ammo, Equipment, Parts and Complete Chassis category filters.
- Individual chassis parts separated from whole-unit offers.
- Alphabetical and per-item value sorting in ascending or descending order.
- All and Alphabetical Ascending selected by default.

## Requirements

An existing compatible **RogueTech** installation with **ModTek**, **RogueTech Core** and **CustomSalvage**. Dependencies are not bundled.

CustomSalvage is by [Denadan](https://github.com/Denadan/CustomSalvage).

## Install

**Vortex 1.14+:** Manage BATTLETECH, use **Install From File** with the release ZIP, enable the mod, then **Deploy Mods**. The archive selects Vortex's game-root deployment type to place files under `BATTLETECH/Mods/BetterSalvageFilter`, rather than the Documents mod folder. Nexus Collections are not supported by this override-based package.

**Manual:** Extract the ZIP's `Mods` folder into the game directory containing `BattleTech.exe`. The root `vortex_override_instructions.json` is Vortex installer metadata and is not needed for manual installation.

Close the game before installing. Avoid duplicate manual/Vortex installations. Launch normally through RogueLauncher and follow RogueTech's current safety and online rules; this mod does not grant online-play approval.

## Scope

Version 0.1.0 category filtering, alphabetical/value sorting and appearance were accepted in-game by the user. This is not an exhaustive modpack compatibility guarantee. The Vortex destination contract was checked in a sandbox, not through a live Vortex GUI deployment.
